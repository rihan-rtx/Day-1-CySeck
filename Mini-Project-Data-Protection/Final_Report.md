# 🔐 Personal Data Protection & CIA Compliance Mapping

## Overview
This project focuses on identifying personal data, analyzing associated risks,
and mapping security controls to the CIA Triad to ensure data protection.

## Objectives
- Identify sensitive personal data
- Analyze risks to personal data
- Apply security controls
- Map controls to CIA Triad

## Module 1: Data Identification

| Data Type | Example |
|---------|--------|
| Documents | College notes, PDFs |
| Photos | Personal images |
| Email | Gmail |
| Cloud Data | Google Drive |

## Module 2: Risk Assessment

| Data | Threat | Vulnerability | Risk |
|----|------|--------------|-----|
| Email | Phishing | Weak password | Account hijack |
| Photos | Malware | No antivirus | Data loss |
| Documents | Ransomware | No backup | Permanent loss |
